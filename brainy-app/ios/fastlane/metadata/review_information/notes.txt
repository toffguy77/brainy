This is a brain training app using Schulte tables (3×3 to 9×9 grids) with four modes: classic, reverse, letters and Gorbov-Schulte. No login or account required. All features work offline. The app is completely free: no in-app purchases, no subscriptions, no ads — every mode and grid size is available. The parent dashboard is protected by a 4-digit PIN that you create on first entry.
