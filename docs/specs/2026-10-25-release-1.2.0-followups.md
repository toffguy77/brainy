# Действия после релиза 1.2.0

Версия 1.2.0 (сборка 16) отправлена на ревью App Store 2026-10-25 и выйдет автоматически после одобрения.
Ниже — всё, что осталось из openspec changes (они заархивированы в `openspec/changes/archive/`):
действия во внешних сервисах и проверки на устройстве. Код и документация закрыты.

## Внешние сервисы

- [ ] RevenueCat: отозвать оба ключа из истории git (ключ из `credentials.md` и iOS SDK-ключ `appl_…` из `app_constants.dart`) или удалить проект; убедиться, что старые ключи отклоняются
- [ ] GitHub: удалить секрет `REVENUECAT_API_KEY` (Settings → Secrets and variables → Actions) — не используется ни одним workflow
- [ ] App Store Connect → App Privacy: снять категорию Analytics; оставить Crash Data, Other Diagnostic Data, Device ID (не связаны с личностью, без трекинга)
- [ ] Firebase console: отключить Google Analytics в проекте `brainy-app-1e48c`
- [ ] Google Cloud (опционально): ограничить iOS API-ключ Firebase bundle ID `com.brainyapp.brainy`
- [ ] GitHub Billing: оплата аккаунта не проходит — приватные репозитории не могут запускать Actions; репозиторий сделан публичным 2026-10-25, чтобы CI и релизы работали

## Проверки CI (однократно)

- [ ] PR с намеренно падающим тестом нельзя слить (обязательные проверки включены)
- [ ] Красный коммит в `main` не загружает сборку (job `deploy` пропускается при упавшем `verify`)

## Проверки на устройстве (TestFlight 1.2.0 (16))

- [ ] Режимы: обратный 3×3 и 9×9, буквы 3×3 и 5×5 (ru и en) — бейдж «Найди» показывает N² / букву; пауза скрывает сетку
- [ ] Размеры 6/7/9, Горбов, дашборд родителя, детальная статистика; переключатель режимов
- [ ] Магазин: купить и надеть по предмету в каждый слот, проверить посадку глифов и плащей на главной, экране персонажа и в магазине; перезапуск — всё сохранилось
- [ ] «Поделиться»: шит на iPhone, поповер у кнопки на iPad; PNG — шрифт Nunito, градиент, рамка
- [ ] Напоминание на русском, английском и немецком (ожидается английский) приходит в локальное время
- [ ] Release-сборка запускается без ошибок ассетов
