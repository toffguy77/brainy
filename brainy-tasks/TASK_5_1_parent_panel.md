# Задание 5.1 — Панель родителя и статистика

> **Используй вместе с MASTER_CONTEXT.md**
> Выполняется после задания 4.2.

---

## Цель

Реализовать панель родителя с PIN-защитой, дашбордом прогресса и детальной статистикой.

---

## PIN-защита

### `lib/features/parent/screens/parent_pin_screen.dart`

- 4-значный PIN (первый раз — установка, последующие — ввод)
- Красивый нумпад с цифрами
- Три точки показывают прогресс ввода
- PIN сохраняется в Hive в зашифрованном виде (используй `flutter_secure_storage`)
- 3 неудачных попытки → блокировка на 30 секунд

---

## Дашборд родителя

### `lib/features/parent/screens/parent_dashboard_screen.dart`

**Структура:**

```
AppBar: «Прогресс ребёнка» + кнопка [Поделиться]

Карточка — Эта неделя:
  ├── 🔥 Стрик: N дней
  ├── ⏱ Среднее время: N сек
  └── 🎮 Сессий: N

График (LineChart из fl_chart):
  └── Время прохождения 5×5 за последние 14 дней
      X: дни, Y: секунды
      Если нет данных — заглушка «Ещё нет данных»

Карточки по размерам таблиц:
  ├── 3×3: лучший результат N сек
  ├── 4×4: лучший результат N сек
  └── 5×5: лучший результат N сек
      (6×6+ только Premium)

Последние 10 сессий (список):
  └── Дата | Размер | Время | Звёзды
```

**Зависимости — добавь в pubspec.yaml:**
```yaml
fl_chart: ^0.66.0
flutter_secure_storage: ^9.0.0
```

---

## Экран настроек родителя

### `lib/features/parent/screens/parent_settings_screen.dart`

**Настройки:**
- Размер таблицы: авто / фиксированный (3×3 / 4×4 / 5×5)
- Максимальное время сессии: 5 / 10 / 15 / без ограничений
- Напоминания: вкл/выкл + время
- Сменить PIN
- Управление подпиской

- [ ] Карточка для соцсетей генерируется как изображение
