## Что такое Brainy

Brainy — мобильное приложение на Flutter для тренировки внимания и скорости чтения у детей 6–14 лет на основе таблиц Шульте. Приложение геймифицировано: персонажи, монеты, стрики, ачивки. Родитель видит прогресс ребёнка через отдельную панель.

**Два рынка:** русскоязычный (RU/CIS) и международный (EN). Локализация с первой версии.

## Целевая аудитория

**Ребёнок (6–14 лет)** — основной пользователь игры. Видит персонажей, получает монеты, собирает ачивки. Интерфейс яркий, игровой, большие кнопки.

**Родитель (мама/папа, 28–40 лет)** — платит за подписку, контролирует прогресс. Интерфейс чистый, информативный. Вход в режим родителя через PIN.

## Игровая механика

### Таблица Шульте
- Сетка N×N с числами от 1 до N² в случайном порядке
- Пользователь тапает числа по порядку (1, 2, 3...)
- Таймер считает время от первого тапа до последнего
- Правильный тап — подсвечивается зелёным и исчезает
- Неправильный тап — лёгкое красное мигание, штраф +2 сек

### Размеры таблиц
| Размер | Уровень | Доступ |
|---|---|---|
| 3×3 | Начинающий | Бесплатно |
| 4×4 | Лёгкий | Бесплатно |
| 5×5 | Стандарт | Бесплатно |
| 6×6 | Сложный | Premium |
| 7×7 | Эксперт | Premium |
| 9×9 | Мастер | Premium |

### Режимы
- **Классический** — числа, по возрастанию
- **Горбова-Шульте** — чёрные числа по возрастанию + красные по убыванию (Premium)

### Адаптивная сложность
Приложение автоматически предлагает следующий размер таблицы когда среднее время за последние 5 сессий ≤ целевого времени:
- 3×3 → цель 9 сек
- 4×4 → цель 16 сек
- 5×5 → цель 25 сек
- 6×6 → цель 36 сек
- 7×7 → цель 49 сек

## Геймификация

### Монеты
Зарабатываются только игрой, **нельзя купить за реальные деньги**:
- Прошёл таблицу → +10 монет
- Личный рекорд → +25 монет
- Стрик 7 дней → +50 монет
- Стрик 30 дней → +200 монет
- Выполнен челлендж → ×2 монеты за сессию

### Стрик
- +1 за каждый день когда сыграна хотя бы 1 сессия
- Визуализация: огонь вокруг персонажа (чем длиннее — ярче)
- Восстановление стрика — 1 раз в месяц (Premium)

### Уровни
XP за каждую сессию = количество клеток в таблице (5×5 = 25 XP)
```
Уровень 1:  0 XP
Уровень 5:  500 XP
Уровень 10: 1500 XP
Уровень 20: 5000 XP
```

### Ачивки (примеры)
- «Первые шаги» — первая сессия
- «Скоростной» — побить личный рекорд 3 раза
- «Неделя» — 7 дней подряд
- «Мастер 5×5» — пройти 5×5 за ≤20 сек
- «Коллекционер» — собрать 10 аксессуаров

### Лиги (еженедельные)
Бронза → Серебро → Золото → Платина
Топ-5 повышаются, нижние 5 понижаются. Участники анонимны (только никнейм).

## Два режима в приложении

### Режим ребёнка
- Яркий, игровой, большие кнопки
- Главный экран: персонаж + [Играть] + монеты + стрик
- Нижняя навигация: Игра / Персонаж / Награды / Лига

### Режим родителя
- Вход через 4-значный PIN
- Чистый дизайн, аналитика
- Дашборд: прогресс за неделю, стрик, динамика
- Настройки: размер таблицы, время сессии, напоминания
- Поделиться прогрессом (красивая карточка для соцсетей)

## Дизайн-система

### Цвета
```dart
primary:     #6C5CE7  // фиолетовый — главный цвет бренда
secondary:   #00CEC9  // бирюзовый — акцент
```

### Шрифты
- Заголовки: **Nunito** (округлый, дружелюбный, работает для детей)
- Тело: **Nunito**
- Цифры в таблице: **Nunito Bold**

### Принципы
- Тёмная тема — основная (выглядит как игра)
- Скруглённые углы (border radius 16–24)
- Анимации на каждое действие (минимум 150–300ms)
- Haptic feedback на каждый тап в игре

## Важные правила кода

1. **Архитектура Feature-first** — каждая фича изолирована в своей папке
2. **Riverpod для всего стейта** — никакого setState в бизнес-логике
3. **Hive для локальных данных** — сессии, настройки, кэш
4. **Firestore для облака** — прогресс, аккаунт, лиги
5. **Игра работает офлайн** — синхронизация когда есть интернет
6. **Никаких magic strings** — все константы в отдельных файлах
7. **Весь текст локализован** — никаких хардкодных строк
