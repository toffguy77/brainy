# Задание 7.2 — Убрать неиспользуемое разрешение камеры

> **Приоритет:** P0 (Apple отклонит приложение)
> **Статус:** Не начато

---

## Проблема

В `ios/Runner/Info.plist` объявлено разрешение камеры:

```xml
<key>NSCameraUsageDescription</key>
<string>Для создания аватара ребёнка</string>
```

Однако в коде приложения **нет функционала камеры** — нет создания аватара, нет съёмки фото. Apple **автоматически отклоняет** приложения, которые запрашивают разрешения, не используемые в приложении.

---

## Что нужно сделать

Удалить из `ios/Runner/Info.plist` строки:

```xml
<key>NSCameraUsageDescription</key>
<string>Для создания аватара ребёнка</string>
```

---

## Файлы для изменения

- `ios/Runner/Info.plist` — удалить NSCameraUsageDescription

---

## Критерии готовности

- [ ] NSCameraUsageDescription удалён из Info.plist
- [ ] Приложение собирается без ошибок
