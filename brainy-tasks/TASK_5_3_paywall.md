> **Используй вместе с MASTER_CONTEXT.md**

## Цель

Реализовать красивый Paywall с тремя планами, анимацией и логикой покупки через RevenueCat.

---

## Paywall экран

### `lib/features/subscription/screens/paywall_screen.dart`

**Структура:**

```
Кнопка [×] закрыть (если можно пропустить)

Заголовок: «Brainy Premium»
Подзаголовок: «Открой всё и тренируйся без ограничений»

Список преимуществ (с анимацией появления по одному):
  ✓ Все размеры таблиц — до 9×9
  ✓ 5 уникальных персонажей
  ✓ Панель прогресса для родителей
  ✓ Без рекламы
  ✓ Режим Горбова-Шульте

Три плана (горизонтальные карточки или вертикальный список):
┌─────────────────┐  ← рекомендуемый, выделен рамкой
│ ГОД             │
│ 1 990 ₽/год     │
│ ~166₽/мес       │
│ [ЛУЧШАЯ ЦЕНА]   │
└─────────────────┘
┌─────────────────┐
│ МЕСЯЦ           │
│ 299 ₽/мес       │
└─────────────────┘
┌─────────────────┐
│ СЕМЬЯ (3 детей) │
│ 2 990 ₽/год     │
└─────────────────┘

Большая кнопка: [Попробовать 7 дней бесплатно]

Мелкий текст: «Отмена в любое время. Управление подпиской в App Store.»

Ссылки: [Восстановить покупки] · [Условия] · [Конфиденциальность]
```

**Поведение:**
- По умолчанию выбран годовой план
- Переключение между планами обновляет текст кнопки
- При нажатии кнопки → `SubscriptionService.purchasePackage()`
- Во время загрузки → показать индикатор на кнопке
- При успехе → закрыть paywall, показать конфетти и сообщение «Добро пожаловать в Premium!»
- При ошибке → показать AlertDialog с текстом ошибки

## Мини-paywall (BottomSheet)

Для случаев когда пользователь тапает на заблокированный контент — показывать компактную версию:

### `lib/features/subscription/widgets/premium_bottom_sheet.dart`

```
Небольшая иконка замка вверху
Заголовок: «Это Premium фича»
Конкретная польза: «Открой таблицы 6×6, 7×7 и 9×9»
Кнопка: [Открыть Premium]
Ссылка: [Попробовать бесплатно 7 дней]
```

Использование:
```dart
showModalBottomSheet(
  context: context,
  builder: (_) => PremiumBottomSheet(
    feature: 'Таблица 6×6',
    benefit: 'Тренируйся на сложных уровнях',
  ),
);
```

## Критерии готовности

- [ ] Paywall отображает реальные цены из RevenueCat
- [ ] Переключение между планами работает
- [ ] Кнопка покупки корректно обрабатывает успех и ошибку
- [ ] После успешной покупки Premium-контент разблокируется
- [ ] Restore purchases работает
- [ ] Мини-paywall (BottomSheet) используется во всех местах блокировки
- [ ] Экран соответствует требованиям App Store (обязательные ссылки присутствуют)
