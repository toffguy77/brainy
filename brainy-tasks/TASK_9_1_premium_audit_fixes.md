## 1. Режим Горбова-Шульте (Premium)

### Что это

Модификация таблицы Шульте с двумя наборами чисел разного цвета. Игрок чередует:
- **Белые числа** — по возрастанию: 1, 2, 3...
- **Красные числа** — по убыванию: max, max-1, max-2...

Последовательность: белая 1 → красная max → белая 2 → красная (max-1) → ...

### Доступные размеры

Только для таблиц ≥ 5×5: **5×5, 6×6, 7×7, 9×9**.

Распределение чисел для таблицы N×N:
- Белых: `ceil(N²/2)`, значения 1..ceil(N²/2)
- Красных: `floor(N²/2)`, значения 1..floor(N²/2)

Примеры:
- 5×5 (25 клеток): 13 белых + 12 красных
- 7×7 (49 клеток): 25 белых + 24 красных

### Home Screen

**Новый переключатель режима** между персонажем и пикером размера:
- Segmented control: «Классика / Горбов»
- PRO бейдж на кнопке Горбов
- Тап на Горбов без подписки → `showPremiumBottomSheet()`
- При выборе Горбова пикер показывает только размеры ≥ 5
- При выборе Классики — все размеры (3–9)

**Подгонка layout** для маленьких экранов (iPhone SE):
- Аватар: 200 → 160px
- Spacer flex: 2 → 1
- Высота тогла: ~40px

### Модель данных

**`GridCell`** — добавить поле `color`:
```dart
class GridCell {
  final int number;
  final int row;
  final int col;
  final String color; // 'white' | 'red'
  bool isFound;
  bool isError;
}
```

**`GameState`** — добавить поля для отслеживания чередования:
- `nextWhiteNumber` — следующее белое число
- `nextRedNumber` — следующее красное число
- `nextExpectedColor` — 'white' или 'red'

### Игровая логика (GameProvider)

**Генерация сетки `_generateGorbovGrid(int size)`:**
1. Рассчитать количество белых и красных
2. Сгенерировать два набора чисел
3. Назначить цвета, перемешать позиции

**Обработка тапа в режиме gorbov:**
1. Проверить, что цвет ячейки совпадает с ожидаемым
2. Если белая — проверить number == nextWhiteNumber
3. Если красная — проверить number == nextRedNumber
4. Правильно → отметить, сдвинуть счётчик, переключить цвет
5. Неправильно → ошибка + штраф

### UI

**SchulteGrid** — отрисовка цветных ячеек:
- Белые: текущий светлый текст (без изменений)
- Красные: красный текст на тёмном фоне
- Найденные: зелёная галочка (как в классике)

**Прогресс-бар** — показывать ожидание: «Найди: белую 3» / «Найди: красную 10»

**Game header** — индикатор режима (бейдж «Горбов» или биколорная иконка)

### Сессии и рекорды

- Сессии сохраняются с `mode: 'gorbov'`
- Рекорды отслеживаются отдельно по режимам и размерам
- В панели родителя сессии Горбова отображаются отдельно

## 4. Панель родителя — Premium-фича

### Поведение

После верификации PIN проверить подписку:
- **Premium:** показать полный дашборд (без изменений)
- **Free:** показать экран-заглушку вместо дашборда

### Экран-заглушка

Полноэкранный upsell:
- Замыленный/затемнённый превью дашборда (или статичная иллюстрация)
- Иконка замка + «Панель прогресса для родителей»
- Подзаголовок: «Следите за прогрессом ребёнка с подробной статистикой»
- Кнопка: «Открыть с Premium» → навигация на `/paywall`
- Кнопка назад → на home

### Настройки

Экран настроек (`/parent/settings`) остаётся доступным ВСЕМ — и бесплатным, и Premium. Блокируется только дашборд.
