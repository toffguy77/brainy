# Задание 7.13 — Проверить и настроить сплэш-экран

> **Приоритет:** P1
> **Статус:** Не начато

---

## Проблема

В `pubspec.yaml` настроен `flutter_native_splash`:

```yaml
flutter_native_splash:
  color: "#0D0D1A"
  image: assets/splash/splash_logo.png
  android: true
  ios: true
```

Нужно убедиться что:
1. Файл `assets/splash/splash_logo.png` существует и содержит логотип
2. Команда генерации была выполнена
3. Сплэш корректно отображается на обеих платформах

---

## Что нужно сделать

### 1. Проверить наличие ассета

```bash
ls -la brainy-app/assets/splash/
```

Если файла нет — создать логотип:
- Размер: 1152 × 1152 px (рекомендуется)
- Содержание: белый логотип Brainy (мозг с глазами) на прозрачном фоне
- Формат: PNG с прозрачностью

### 2. Сгенерировать нативный сплэш

```bash
cd brainy-app
dart run flutter_native_splash:create
```

### 3. Проверить результат

- Запустить на iOS симуляторе — должен показать логотип на тёмном фоне (#0D0D1A)
- Запустить на Android эмуляторе — аналогично
- Убедиться что переход от splash к приложению плавный

---

## Файлы для изменения

- `assets/splash/splash_logo.png` — создать если нет
- Сгенерированные файлы обновятся автоматически командой

---

## Критерии готовности

- [ ] `assets/splash/splash_logo.png` существует
- [ ] `dart run flutter_native_splash:create` выполнена успешно
- [ ] Сплэш отображается на iOS
- [ ] Сплэш отображается на Android
- [ ] Переход от сплэша к приложению плавный
