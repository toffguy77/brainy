# Задание 2.3 — Экран результата и рекорды

> **Используй вместе с MASTER_CONTEXT.md**
> Выполняется после задания 2.2.

## Цель

Реализовать экран результата после завершения игры: время, звёзды, монеты, анимация личного рекорда, кнопки «Сыграть ещё» и «Домой».

---

## Экран результата

### `lib/features/game/screens/result_screen.dart`

**Структура экрана сверху вниз:**
1. Анимированный заголовок (рекорд или обычный результат)
2. Большое время в центре
3. Три звезды (1–3 в зависимости от результата)
4. Карточки: монеты заработаны / ошибки / личный рекорд
5. Кнопки действий

**Логика звёзд:**
- 3 звезды: время ≤ 80% от целевого (gridSize²)
- 2 звезды: время ≤ 120% от целевого
- 1 звезда: всё остальное

**Логика данных:**
- Экран получает `session: GameSession` и `isRecord: bool` через `GoRouter extra`
- Если `isRecord == true` — показать анимацию конфетти + текст «Личный рекорд!»
- Монеты: показать +N с анимацией появления

**Анимации:**
- Звёзды появляются по одной с задержкой 200ms
- Если рекорд — конфетти сверху (используй пакет `confetti: ^0.7.0`)
- Монеты считаются с 0 до N за 1 секунду

**Кнопки:**
- `[Сыграть ещё]` — тот же размер таблицы, `context.go('/game', extra: ...)`
- `[Домой]` — `context.go('/game')`

---

## Критерии готовности

- [ ] Экран получает данные сессии из GoRouter extra
- [ ] Отображается правильное время с форматом (например: «28 сек» или «1:23»)
- [ ] Звёзды (1, 2 или 3) соответствуют результату
- [ ] При личном рекорде — анимация конфетти и бейдж «Новый рекорд!»
- [ ] Монеты анимированно считаются от 0 до заработанного значения
- [ ] Кнопка «Сыграть ещё» запускает новую игру с тем же gridSize
- [ ] Кнопка «Домой» возвращает на главный экран
