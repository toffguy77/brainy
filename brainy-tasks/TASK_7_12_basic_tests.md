## Минимальный набор тестов для релиза

### 1. Unit-тесты моделей

**Файл:** `test/models/session_test.dart`
- Создание GameSession с корректными данными
- Вычисление звёзд по порогам
- Вычисление XP (gridSize²)

**Файл:** `test/models/user_progress_test.dart`
- Начальные значения (0 монет, 0 XP, уровень 1)
- Обновление стрика (новый день = +1, тот же день = без изменений)
- Вычисление уровня по XP

### 2. Unit-тесты игровой логики

**Файл:** `test/game/game_logic_test.dart`
- Генерация сетки NxN содержит числа от 1 до N²
- Все числа уникальны
- Правильный ответ (nextNumber) принимается
- Неправильный ответ отклоняется
- Пенальти за ошибку (2 секунды)

### 3. Unit-тесты звёздных порогов

**Файл:** `test/game/star_thresholds_test.dart`
- 3×3 за 7 секунд → 3 звезды
- 3×3 за 12 секунд → 2 звезды
- 3×3 за 20 секунд → 1 звезда
- Проверить все размеры сеток

### 4. Unit-тесты монет и XP

**Файл:** `test/game/coins_xp_test.dart`
- Базовые монеты за сессию (10)
- Бонус за рекорд (+25)
- XP = gridSize²
- Переход на следующий уровень
