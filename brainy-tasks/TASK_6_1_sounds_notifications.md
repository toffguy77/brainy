# Задание 6.1 — Звуки, хаптика и уведомления

> **Используй вместе с MASTER_CONTEXT.md**
> Выполняется после задания 5.3.

---

## Цель

Добавить звуковую обратную связь, haptic feedback и push-уведомления для стрика.

---

## Звуки

Добавь в `pubspec.yaml`:
```yaml
audioplayers: ^5.2.1
```

### `lib/shared/services/sound_service.dart`

Звуки (используй бесплатные из freesound.org или zapsplat.com):

| Ключ | Когда играть |
|---|---|
| `tap_correct` | Правильный тап в игре |
| `tap_wrong` | Неправильный тап |
| `game_complete` | Завершение игры |
| `record_broken` | Личный рекорд |
| `achievement` | Получение ачивки |
| `coins` | Начисление монет |
| `level_up` | Повышение уровня |
| `streak` | Обновление стрика |

**Важно:** настройка «Звуки вкл/выкл» в настройках → сохранять в Hive.

---

## Haptic Feedback

Используй `HapticFeedback` из `flutter/services.dart`:

| Событие | Тип хаптики |
|---|---|
| Правильный тап | `HapticFeedback.lightImpact()` |
| Неправильный тап | `HapticFeedback.heavyImpact()` |
| Завершение игры | `HapticFeedback.mediumImpact()` (3 раза с 100ms паузой) |
| Личный рекорд | `HapticFeedback.vibrate()` |
| Покупка | `HapticFeedback.mediumImpact()` |

---

## Push-уведомления

Добавь в `pubspec.yaml`:
```yaml
flutter_local_notifications: ^17.0.0
timezone: ^0.9.2
```

### `lib/shared/services/notification_service.dart`

**Типы уведомлений:**

1. **Напоминание о тренировке** (ежедневное)
   - Время: устанавливает родитель в настройках (по умолчанию 17:00)
   - Тексты (чередующиеся, чтобы не надоедало):
     - «🔥 Брейни ждёт! Не потеряй стрик»
     - «🧠 Время потренировать мозг!»
     - «⚡ Зэп зовёт на тренировку!»

2. **Предупреждение о потере стрика** (если не играли сегодня, вечером)
   - В 20:00 если нет сессии за сегодня и стрик > 2
   - «🚨 Стрик {N} дней сгорит сегодня!»

**Разрешение на уведомления** — запрашивать в конце онбординга (страница 5), не в начале.
