# Задание 7.11 — Очистка неиспользуемых зависимостей

> **Приоритет:** P2
> **Статус:** Не начато

---

## Проблема

В `pubspec.yaml` есть зависимости, которые могут быть не нужны или не используются активно:

### Потенциально лишние

| Пакет | Причина сомнений |
|---|---|
| `firebase_auth: ^5.5.1` | Нет экрана логина/регистрации. Если авторизация не используется — лишний вес |
| `cloud_firestore: ^5.6.5` | Firestore подключён, но основное хранилище — Hive. Проверить реальное использование |
| `lottie: ^3.3.1` | Директория анимаций пуста (только .gitkeep) |
| `google_mobile_ads: ^5.3.0` | Если решено убрать рекламу (см. TASK_7_3) |

---

## Что нужно сделать

### 1. Проверить использование каждого пакета

```bash
cd brainy-app

# Для каждого пакета проверить импорты
grep -r "firebase_auth" lib/
grep -r "cloud_firestore" lib/
grep -r "lottie" lib/
grep -r "google_mobile_ads" lib/
```

### 2. Удалить неиспользуемые

Для каждого неиспользуемого пакета:
1. Удалить из `pubspec.yaml`
2. Удалить импорты из Dart-файлов
3. `flutter pub get`
4. Проверить что приложение собирается

### 3. Проверить iOS Podfile

После удаления пакетов:
```bash
cd ios
pod deintegrate
pod install
```

---

## Файлы для изменения

- `pubspec.yaml` — удалить неиспользуемые зависимости
- `lib/**/*.dart` — удалить неиспользуемые импорты
- `ios/Podfile.lock` — обновится автоматически

---

## Критерии готовности

- [ ] Все зависимости в pubspec.yaml реально используются в коде
- [ ] Приложение собирается без ошибок после очистки
- [ ] Размер приложения уменьшился
