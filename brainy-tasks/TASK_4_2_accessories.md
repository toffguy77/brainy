## Цель

Реализовать магазин аксессуаров и редактор персонажа.

---

## Модель аксессуара

### `lib/models/accessory.dart`

```dart
enum AccessorySlot { hat, glasses, effect, cape }

class Accessory {
  final String id;
  final String nameRu;
  final String nameEn;
  final AccessorySlot slot;
  final int price;          // цена в монетах
  final String assetPath;
  final bool isPremium;     // только для подписчиков
}
```

---

## Стартовые аксессуары (для MVP — текстовые плейсхолдеры)

Минимум 15 аксессуаров:
- 5 шляп: Колпак учёного, Корона, Кепка, Шлем, Цилиндр
- 4 очки: Умные очки, Солнцезащитные, Пиксельные, VR-шлем
- 3 эффекта: Звёзды, Огонь, Электричество (Premium)
- 3 плаща: Мантия, Плащ ниндзя, Крылья

---

## Экран аксессуаров

### `lib/features/character/screens/accessories_screen.dart`

**Структура:**
```
AppBar: «Кастомизация»

Превью персонажа с надетыми аксессуарами (верхняя треть экрана)

Табы: Шляпы | Очки | Эффекты | Плащи

GridView аксессуаров (2 колонки):
  ├── Куплен и надет → зелёная рамка, галочка
  ├── Куплен, не надет → синяя рамка, кнопка [Надеть]
  ├── Не куплен, доступен → цена в монетах, кнопка [Купить]
  └── Premium → замочек, кнопка [Premium]
```

**При покупке:**
1. Проверить достаточно ли монет
2. Если да — списать монеты, добавить аксессуар в `unlockedAccessories`
3. Показать анимацию покупки
4. Автоматически надеть

## Критерии готовности

- [ ] Все 15+ аксессуаров отображаются по категориям
- [ ] Покупка за монеты работает корректно
- [ ] Надевание аксессуара обновляет превью мгновенно

- [ ] Состояние сохраняется в Hive
